Key Finding: Regularized linear models (LR-L2, LR-L1, Linear SVM) dominate on the 483-feature sparse binary dataset. 📋 Evaluation Protocol & Criteria

Primary Metrics

  • Balanced Accuracy — primary selection metric
  • Macro-F1 — class-balanced harmonic mean
  • FPR / FNR — operational error rates
  • ROC-AUC / PR-AUC — ranking quality

Validation Protocol

  • Expanding-window temporal CV (3 folds)
  • Chronological validation slice (20%)
  • Test set: one-shot final evaluation
  • Bootstrap 95% CI (1,000 resamples)

Operational Constraints

  • FPR budget: ≤ 1% (SOC alert fatigue)
  • Seed: 42 (reproducibility)
  • CPU-only inference (no GPU)
  • Temporal discipline enforced

Feature Categories Explained

API Calls (312): Dynamic function call traces from Cuckoo sandbox — NtProtectVirtualMemory, LdrGetProcedureAddress
String Patterns (108): Static PE string extraction — !this program cannot be run in dos mode
PE Signatures (63): Packer/entropy signatures — packer_entropy, pe_section_*
⚠️
False Positive Root Cause: The feature STRING:!this program cannot be run in dos mode has the highest positive LR coefficient (+2.599) and fires in 100% of false positives. Modern 2023–24 software (Zoom, VALORANT, CyberGhost) are single-PE executables containing this standard DOS stub. The model learned a static compilation artifact, not malicious behaviour.
